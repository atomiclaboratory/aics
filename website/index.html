THE AI CONTEXT SITEMAP PROTOCOL (v1.0.0)

STOP DUMPING RAW FILES INTO CONTEXT WINDOWS.
Generate holographic skeletons of your codebase to prevent hallucination and save 95% of tokens.

> npm install -g @aics/cli

:: THE PROBLEM

  • Raw Code is Expensive: Dumping 50 files into Claude/GPT-4 costs $$$ and wastes tokens.
  • Context Dilution: Too much implementation detail confuses the Agent ("Lost in the Middle" phenomenon).
  • Hallucinations: Agents guess your API because they can't "see" the whole project.

THE SOLUTION: A standardized .ai-index.md file. A "Holographic Map" containing only signatures, types, and relationships. 50k tokens -> 2k tokens.

:: QUICK START

1. INITIALIZE

Create the config file in your project root.

C:\Project> aics init

2. GENERATE SITEMAP

Scans your source and writes .ai-index.md.

C:\Project> aics gen

3. CONFIGURE AGENT

Add this to your .cursorrules or System Prompt:

CONTEXT_BEHAVIOR: - ALWAYS load ".ai-index.md" as the primary map of the codebase. - REFER to ".ai-index.md" BEFORE reading raw files.

:: CLI REFERENCE

> aics gen (alias: generate) _

Main build command. Optimizes context.

FLAG DESCRIPTION DEFAULT
-i, --input Override input glob From config
-o, --output Output filename .ai-index.md
-b, --budget Max token budget 32000
--watch Watch mode (Dev) false

> aics check

CI/CD enforcer. Prevents drift between code and index.

  • --strict: Exit code 1 on drift.
  • --lock-only: Fast hash check.

:: BIOINFORMATICS & DOCS SUPPORT NEW!

AICS is now multimodal. It can index massive biological datasets and documentation without reading the full payloads.

> aics bio-gen

Creates "Bio-Holograms" for Multi-Omics data (CyTOF, RNA-Seq).

Supported Formats:
- .fcs (CyTOF)    -> Extracts Panel Map & Event Count
- .fastq.gz (Seq) -> Extracts Read Length & Quality
- .bam (Align)    -> Extracts Reference Genome (hg38/mm10)
- .csv (Olink)    -> Extracts Schema & Sparsity Check

Documentation & LLM Summaries

We support .pdf, .docx, and .md. If you provide an API Key, we use LLMs to summarize them into one sentence.

COST SAVING: Summaries are cached in .aics-lock.json. API is ONLY called when file content changes.

:: CONFIGURATION (aics.config.json)

{
  "input": ["src/**/*.ts", "docs/*.pdf"],
  "output": ".ai-index.md",
  "budget": 32000,
  
  // TIERING STRATEGY
  "tiers": {
    "protected": ["src/core/**"], // Never compress these
    "skeleton": ["src/utils/**"]  // Strip types, keep sigs
  },

  // LLM SUMMARIZER (Optional)
  "llm": {
    "provider": "openai", // or "gemini"
    "apiKey": "sk-...",   // or set env OPENAI_API_KEY
    "model": "gpt-4o-mini"
  },

  // SECURITY
  "secrets": {
    "patterns": ["*KEY*", "*SECRET*", "password"]
  }
}

The 4 Sections of an Index

  1. FEDERATION: Links to external indexes (node_modules).
  2. THE MAP: High-level routing (File paths + Keywords).
  3. SKELETONS: AST-stripped code signatures (The meat).
  4. ANCHORS: Links code to Tests (Ground truth usage).
